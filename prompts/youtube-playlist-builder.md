# YouTube Playlist / Reference Builder Prompt

```text
Build a human-curated reference shortlist for guitar practice.

Input:
- Style lane: {{style_lane}}
- Technique focus: {{technique_focus}}
- Mood / era / adjacent styles: {{mood_era_adjacent}}
- Exclusions: {{exclusions}}

Output:
1. Reference search themes
2. Candidate track types to look for
3. What traits to extract from each reference
4. A shortlist table template for human curation
5. Practice translation prompts

Rules:
- Do not promote references automatically
- Treat references as trait sources, not imitation targets
- Include why a reference is useful musically
- Prefer a small curated list over a large unfocused playlist
```
