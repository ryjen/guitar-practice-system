# Rhythm Groove Generator Prompt

```text
Generate a rhythm and groove practice spec for guitar.

Input:
- Style lane: {{style_lane}}
- Technique: {{technique}}
- Tempo: {{tempo}}
- Feel: {{feel}}
- Reference traits: {{reference_traits}}
- Constraint: {{constraint}}

Output:
1. Groove title
2. Core count / subdivision
3. Muting and accent plan
4. Bass or drum lock point
5. Two-bar riff cell
6. Four-bar variation
7. One simplification
8. One harder version
9. Suggested backing-track cue

Rules:
- Make rhythm explicit
- Say where the accents land
- Use rests and space intentionally
- Keep the exercise short enough to loop
```
