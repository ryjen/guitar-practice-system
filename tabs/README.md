# Tabs and Notation

This directory is for curated notation-oriented artifacts and notes.

## Policy

Do not use tab or notation exports as the only source of truth unless explicitly promoted.

Preferred flow:

1. Markdown practice spec
2. MIDI scaffold for timing
3. MusicXML for interchange
4. MuseScore for editing / rendering
5. Guitar Pro only when guitar-specific notation is useful

## Promotion checklist

Promote notation here only when:

- the exercise was useful to practice
- the rhythm is clear
- tuning / capo / key are documented
- the source spec is linked
- the file is small enough to reuse
