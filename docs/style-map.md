# Style Map

## Purpose

Convert references into actionable musical traits.

Do not copy artists directly. Extract useful constraints: rhythm, texture, register, tone movement, arrangement shape, and energy curve.

## Core lanes

| Lane | Actionable traits | Practice material |
|---|---|---|
| U2 / rhythmic delay | dotted-eighth feel, chiming triads, sparse voicings, bass/drum lock, delay-as-rhythm | delay grid exercises, arpeggio vamps, section cue maps |
| Post-punk driving bass | root motion, eighth-note pulse, minor/modal harmony, clipped guitar accents | bassline-led loops, muted guitar hooks, motorik drum specs |
| Ambient / E-Bow | drones, slow counterlines, volume swells, suspended harmony, transitions | drone beds, two-note motifs, transition textures |
| Expressive wah | filter accents, vowel movement, half-cocked resonance, call-response phrasing | wah articulation drills, accent maps, riff variations |

## Adjacent future lanes

| Lane | Useful traits |
|---|---|
| Shoegaze | dense sustain, tremolo picking, blurred chord identity, reverse/reverb washes |
| New wave | clean rhythmic comping, synth-like guitar hooks, tight sections |
| Goth rock | chorus bass, minor-key arpeggios, spacious drums, dramatic dynamics |
| Krautrock | motorik pulse, repetition, small variation, hypnotic structure |
| Cinematic western | tremolo, baritone-like lines, open intervals, sparse reverb |
| Art rock | asymmetry, unusual section lengths, textural contrast |

## Reference extraction checklist

For each reference, extract:

- tempo range
- groove type
- bass role
- drum energy
- guitar register
- chord vocabulary
- effect role
- section shape
- one constraint to practice

## Example extraction

Reference trait: chiming rhythmic delay guitar

Practice translation:

- 104 BPM
- dotted-eighth delay feel
- two-string triads
- avoid full strummed chords
- bass owns the root motion
- guitar supplies syncopated upper-register hooks
