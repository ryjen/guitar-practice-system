# Score IR Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement issue #110: one strict, versioned, deterministic Score IR domain contract with validation and canonical JSON round-tripping.

**Architecture:** Add a pure `guitar_practice.domain.score` module containing only canonical symbolic-music validation and serialization. The representation remains JSON-compatible dictionaries/lists so application/CLI/import/export layers can consume it without domain dependencies on storage or adapters. Exact rational bar-local timing prevents MIDI tick resolution or notation-engine details from becoming canonical state.

**Tech Stack:** Python 3.12 standard library (`json`, `fractions`, `math`, `re`), `unittest`, existing repository layering tests.

**Spec:** `docs/architecture/score-ir.md`

## Global Constraints

- Canonical schema id is exactly `guitar-practice.score`.
- Initial schema version is integer `1`; unsupported versions fail closed.
- Domain code must not import CLI, filesystem, process, network, application, adapter, or presentation modules.
- JSON serialization is deterministic: sorted object keys, compact separators, UTF-8 text semantics, one trailing newline.
- Bar-local beats are 1-based rational meter-unit positions; durations are positive rational fractions of a whole note.
- MuseScore, Guitar Pro, MusicXML, MIDI byte encoding, audio renderer, RC-3, filesystem paths, and implicit CLI state are not Score IR domain state.

Create `score.py` with:

```python
SCHEMA_ID = "guitar-practice.score"
SCHEMA_VERSION = 1

class ScoreError(ValueError):
    pass


def validate(document: dict[str, Any]) -> None:
    if not isinstance(document, dict):
        raise ScoreError("score must be an object")
    missing = _REQUIRED_TOP_LEVEL - set(document)
    if missing:
        raise ScoreError(f"score is missing required fields: {sorted(missing)}")
    if document.get("schema") != SCHEMA_ID:
        raise ScoreError(f"schema must be {SCHEMA_ID!r}")
    if document.get("version") != SCHEMA_VERSION:
        raise ScoreError(f"version must be {SCHEMA_VERSION}")


def dumps(document: dict[str, Any]) -> str:
    validate(document)
    return json.dumps(document, ensure_ascii=False, sort_keys=True, separators=(",", ":")) + "\n"


def loads(text: str) -> dict[str, Any]:
    document = json.loads(text, object_pairs_hook=_unique_object)
    if not isinstance(document, dict):
        raise ScoreError("score JSON root must be an object")
    validate(document)
    return document
```

Top-level validation must require `schema`, `version`, `id`, `metadata`, `bars`, `meter_map`, `tempo_map`, `parts`, reject unknown top-level fields except documented optional version-1 fields, and validate the score id/title plus contiguous bar numbering and first meter entry.
