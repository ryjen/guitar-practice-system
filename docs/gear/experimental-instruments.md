# Experimental Instruments

## Electric cigar-box banjo

- **ID:** `instrument-cigar-box-banjo-electric`
- **Category:** Electric folk / experimental string instrument
- **Model:** Exact builder and configuration unconfirmed
- **Amplification:** Electric output; route through a clean amp or interface first
- **Role:** Optional creative instrument, not part of the mandatory core progression

### Supported use cases

- Slide experimentation where the neck, action, and string spacing permit it
- Alternate tunings and drone-based practice
- Americana, roots, and percussive textures
- Songwriting and arrangement colour
- Layered backing-track parts
- E-Bow experimentation only if pickup geometry and string response allow reliable activation

### Technique links

- Slide path (`#4`)
- E-Bow path (`#6`), experimental compatibility only

### Setup guidance

Start with:

```text
cigar-box banjo -> clean amplifier or interface -> dry monitoring
```

Record tuning, scale/string layout, pickup behaviour, and noise before adding gain, compression, delay, or reverb. Do not assume guitar-specific fingering, intonation, or E-Bow behaviour transfers directly.

### Boundary

This instrument remains independently selectable. Its experiments must not block progression or maintenance for slide, wah, E-Bow, country picking, or the primary guitars.
